# Apache Iceberg (Unofficial) Resources in Japan

A page listing Apache Iceberg events, blog posts, podcasts, books, and slides from Japan. This is an unofficial community page.

## Publishing (GitHub Pages)

1. Put the contents of this folder at the root of the repository.
2. In Settings > Pages, select the branch (main) and the root folder.

## Adding entries

Add entries to `data.js` and send a pull request. You can also add `title_en` or `note_en` for the English view (if omitted, the Japanese text is shown as is).

## Inclusion criteria (draft)

- The content is about Apache Iceberg.
- The content is in Japanese, or the event is held in Japan.
- Promotional content is acceptable as long as it is mainly technical.
